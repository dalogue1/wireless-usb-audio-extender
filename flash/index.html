Wireless USB Audio Extender

Web flasher, firmware 1.4.1-dev. Flash both boards with the same version.

This browser can't flash boards. Use Chrome or Edge on a desktop computer (Windows, macOS, Linux).

Click a board's button below, choose its serial port, and confirm. Each takes about a minute; unplug the board when it's done. First put the board into flashing mode:

  • XIAO ESP32-S3: hold its BOOT button while you plug it in with a USB data cable, then release it (otherwise no device appears).
  • M5Stack AtomS3U: plug it in, then hold its side button for about 2 s until the green LED inside lights up, and release it.

1. Local board (plugs into the PC)

Install: the first time, or to start over (resets config.txt, voice files and saved settings). Update: from 1.1 or later, keeps them. The same firmware runs on a XIAO ESP32-S3 or an AtomS3U, with either kind of remote.

2. Remote board (goes with the microphone)

The same firmware runs on a XIAO ESP32-S3 (with a USB audio adapter) or an AtomS3U (built-in microphone), with either kind of local board. Once flashed, the XIAO remote's USB-C port works as a USB host for the audio adapter, so it never shows up as a port unless BOOT is held while plugging it in.

Then

After installing a local board, leave it plugged in for about 20 seconds: on its first start it writes its files (voice clips, README) to its drive. Then unplug both boards. Assemble the remote (board, OTG splitter, audio adapter, microphone, 5 V power; an AtomS3U remote just plugs into a 5 V USB power supply) and plug the local board into the computer. Within a few seconds the computer has a new microphone, Extender Mic 1. No settings needed.
